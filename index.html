Quick help

  1. Choose Draw and a New box class. Drag anywhere on the image, including inside an existing box.
  2. Choose Edit, then tap a box or its row. Drag inside to move it, drag a corner to resize it, or use Change selected box class.
  3. To mark an image as a background image with no target object, choose Confirm no object. This creates an empty label file.
  4. Boxes smaller than 3 original-image pixels are rejected.

Shortcuts: A/← previous, D/→ next, 1–9 classes, Delete remove box, Ctrl/Cmd+Z undo, Ctrl/Cmd+S download draft, Esc cancel/deselect.

All work remains local. For ZIP sessions, use Download draft ZIP in Dataset Summary before closing. Reopen the draft with Import Images ZIP. In compatibility mode the original folder cannot be updated directly.
